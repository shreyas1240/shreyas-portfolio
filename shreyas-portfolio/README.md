# Shreyas G. — Personal Portfolio

A responsive Midnight Blue portfolio built with Next.js App Router, React, Framer Motion and custom CSS.

## Run locally

1. Install Node.js LTS from https://nodejs.org/.
2. Open this folder in VS Code.
3. Open Terminal → New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open http://localhost:3000.

## Personalize before publishing

- Add your portrait as `public/profile.jpg` (JPG/PNG/WebP; a square or portrait crop works best).
- Add your latest resume as `public/Shreyas_G_Resume.pdf` so the Download Resume button works.
- In `app/page.tsx`, replace the LinkedIn placeholder URL with your actual LinkedIn profile URL.
- Verify every resume detail and project metric before publishing. The content currently follows the uploaded resume.

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Sign in at https://vercel.com/ and choose Add New → Project.
3. Import the repository. Vercel should detect Next.js automatically.
4. Keep the default build settings and click Deploy.

No environment variables are required for this starter.
